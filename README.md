# 星空全能工具站 · xkmyth 工具站

xkmyth（星空神话）生态旗下的实用工具箱，纯静态单页。

- 在线访问：https://xkmyth.github.io/Timarsky/
- 主站：https://xkmyth.github.io/

## 内容

28 大模块 / 723 个实用工具，覆盖：

- 🖥️ Windows 系统快捷键与维护
- 📐 CAD 制图常用技巧
- 📊 Office 办公效率
- 🎨 Photoshop / 设计
- 💻 编程开发
- 🔧 运维排障
- 🏕️ 生活应急与户外

每个工具卡片支持「展开 / 复制」，一键把内容拷走。

## 技术

纯静态：`index.html`（单页全部内容）+ `style.css` + `main.js` + `script.js`，另有明暗主题切换与「回到顶部」。

什么时候用

把用户口令派生成固定长度密钥，再拿去加密。

怎么用

  1. 填消息、密码或密钥
  2. 设置算法与参数
  3. 点执行，输出哈希 / 签名 / 动态码

长得什么样

password + salt → 32 字节密钥（15 万轮）

注意

迭代次数越高越安全也越慢；每个用户必须有独立随机盐。

什么时候用

临时把一张小 CSV 灌进数据库，写 INSERT 时最怕单引号与 NULL 混在一起。

怎么用

  1. 把代码或数据结构粘进输入框
  2. 选择风格或参数
  3. 结果可复制；语法有错会指出位置

长得什么样

表 users，CSV 三列 id,name,email · 输出 INSERT INTO `users` (`id`,`name`,`email`) VALUES (1,'张三','a@b.c');

注意

空单元格按 NULL 写，看起来像数字的直接不加引号。这只适合几十几百行的数据导入，大文件请用 COPY/LOAD DATA。

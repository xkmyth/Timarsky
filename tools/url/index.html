什么时候用

分享出来的链接带一堆 %E4%BD%A0，解一下才知道指向哪。

怎么用

  1. 把要处理的文本粘进输入框
  2. 选方向（编码 / 解码）或填好参数
  3. 点按钮或直接输入，结果可一键复制

长得什么样

%E4%BD%A0%E5%A5%BD → 你好

注意

encodeURIComponent 会把 / : ? 也转义；要保持 URL 结构的整串编码要用 encodeURI。

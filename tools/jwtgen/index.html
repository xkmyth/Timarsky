什么时候用

调接口时经常需要一个能过签名的 token 来试权限，手写 base64 容易漏掉 padding 与 URL 安全字符。

怎么用

  1. 填消息、密码或密钥
  2. 设置算法与参数
  3. 点执行，输出哈希 / 签名 / 动态码

长得什么样

payload = {"sub":"demo","exp":1750000000}；密钥 = test-secret · 输出三段 base64url，中间那个解出来就是你的 payload

注意

工具只做 HS256。exp 是秒级时间戳，写 0 表示不设过期——测试可以，线上别这么干。密钥别贴进公开的 Issue。
